# Teacher setup

## Ages 10–12
Do NOT create individual GitHub.com accounts for students. GitHub's Terms require users to be at least 13 (and local law may require an older age).
Use local Git repositories on classroom PCs for student practice. The teacher may demonstrate GitHub using the teacher's own account/project. Do not share one login among students.

## Ages 13+
Students may use their own accounts only if they meet GitHub's age requirements and applicable local rules. Use a school/teacher-managed organization if appropriate.

## Suggested software
- VS Code
- Git or GitHub Desktop
- Browser
