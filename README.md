# CreaVerse Junior Developer — Git & GitHub Mission

An educational module for introducing children to professional software-development workflows through practical web projects.

## Course Position

This module is designed to follow introductory **HTML + CSS** learning.

Students already know how to create and modify a simple webpage.  
The purpose of this module is to teach them how developers:

- protect their work,
- save meaningful versions,
- experiment safely,
- investigate mistakes,
- collaborate,
- review changes,
- publish projects,
- and supervise AI-assisted development.

| Professional concept | Student concept |
|---|---|
| Repository | Project Headquarters |
| Commit | Checkpoint |
| History | Time Machine |
| Diff | Detective View |
| Branch | Parallel Universe |
| Pull Request | Upgrade Request |
| Merge | Bring the Upgrade Home |
| AI Coding Agent | Robot Developer |

## Course Structure

The module consists of **8 lessons × 2 hours**.

### Mission 01 — Project Headquarters
Repository and first checkpoint.

### Mission 02 — Checkpoint Challenge
Commits, project history and meaningful commit messages.

### Mission 03 — Time Machine
Investigate a broken project and recover an earlier working version.

### Mission 04 — Parallel Universe
Use branches to experiment without damaging the official project.

### Mission 05 — Upgrade Battle
Review changes and introduce the Pull Request workflow.

### Mission 06 — Git Detectives
Use diffs and history to investigate bugs and collaborate.

### Mission 07 — Robot Developer
Work with an AI coding assistant while keeping the student responsible for reviewing and testing changes.

### Mission 08 — CreaVerse Developer Challenge
Complete the full development workflow:

**IDEA → BRANCH → BUILD → TEST → COMMIT → REVIEW → MERGE → PUBLISH**
